LLAMA SEC

Fine-tuning do TinyLlama 1.1B para Análise de Vulnerabilidades em Cibersegurança

Explorando o potencial de Large Language Models compactos para detecção e análise automatizada de vulnerabilidades

Ver Pesquisa Acessar GitHub

Resumo do Projeto

Objetivo

Este trabalho investiga a aplicação de Small Language Models (SLMs) em Inteligência Artificial Explicável (XAI) para Cibersegurança. O objetivo principal é desenvolver e validar um pipeline de fine-tuning para o modelo TinyLlama-1.1B, visando a interpretação automatizada de logs de segurança com baixo custo computacional.

Motivação

A dependência de alto poder computacional limita o uso de Large Language Models (LLMs) em ambientes locais e críticos. Modelos compactos oferecem uma alternativa viável para preservar a privacidade dos dados e reduzir a latência, permitindo que analistas de segurança obtenham explicações técnicas detalhadas sem depender de nuvens externas.

Principais Contribuições

  • Pipeline SFT Supervisionado: Integração Snort + API Gemini para geração de dados sintéticos.
  • Validação de SLM: TinyLlama-1.1B como assistente local de segurança eficaz.
  • Análise de Contexto: Determinação da janela de 512 tokens como essencial para coerência.
  • Eficiência: Solução de baixo custo para interpretação de incidentes.

Metodologia

Modelo Base

TinyLlama 1.1B

Modelo compacto baseado na arquitetura Llama, com 1.1 bilhão de parâmetros, ideal para fine-tuning em hardware limitado mantendo performance competitiva.

Dataset

Dataset: Logs Snort + Gemini Insights

Dataset híbrido composto por logs reais do IDS Snort enriquecidos com interpretações de ameaças geradas sinteticamente pela API Gemini, criando pares de instrução-resposta de alta qualidade.

Técnica de Treinamento

Técnica: Supervised Fine-Tuning (SFT)

Utilização de SFT para especializar o modelo na tarefa de XAI. O Gemini atuou como "professor" para gerar exemplos de treinamento, permitindo que o TinyLlama aprendesse a articular explicações técnicas.

Infraestrutura

Ambiente: Google Colab
Framework: PyTorch

Experimentos conduzidos em ambiente controlado na nuvem, garantindo reprodutibilidade e acesso a recursos de GPU para o processo de fine-tuning.

Pipeline de Treinamento

  1. Preparação: Conversão de logs Snort para formato textual estruturado.
  2. Enriquecimento: Geração de explanations via API Gemini (Teacher).
  3. Fine-Tuning: Treinamento do TinyLlama-1.1B com os dados sintéticos.
  4. Validação: Monitoramento de Loss e métricas ROUGE.
  5. Avaliação: Comparação qualitativa com limpeza de tokens.

Comparação direta entre o output gerado pelo TinyLlama 1.1B (Fine-tuned) e a Referência (Teacher).

[12/08-00:51:19.501356] ET WEB_SERVER SQL Errors in HTTP 200 Response (mysql_query) 83.170.101.10:80 -> 192.168.13.10:1039
Protocol: TCP TTL:128 ...

TinyLlama 1.1B (Gerado)

Ameaça Provável:

SQL Injection/SQL Inspeção. O alerta sugere que um atacante está tentando explorar uma falha na aplicação para inserir texto malicioso.

Ações Recomendadas:

  1. Isolar o Servidor: Imediatamente, isole o servidor web (192.168.13.10).
  2. Investigar Logs: Analise logs do servidor (Apache/Nginx).
  3. Analisar Tráfego: Verifique conexão HTTP 83.170.101.10.

Referência (Ideal)

Ameaça Provável:

Tentativa de SQL Injection. O servidor está respondendo com erros SQL (mysql_query) em páginas HTTP 200, indicando falha no tratamento de input.

Ações Recomendadas:

  1. Resposta Imediata: Isole o servidor e bloqueie o IP 83.170.101.10.
  2. Análise Forense: Analise logs e código da aplicação.
  3. Remediação: Use prepared statements.

Principais Descobertas

  • Importância do Contexto: Janelas de 512 tokens são cruciais para a qualidade das explicações XAI.
  • Viabilidade do SLM: Modelos compactos podem substituir LLMs em nuvem para tarefas específicas.
  • Ponto de Quebra: Janelas menores que 128 tokens degradam severamente a coerência.
  • Estabilidade: Convergência de aprendizado rápida e estável (4 épocas).

Pontos Fortes

  • Independência de APIs pagas e conexão com internet
  • Privacidade total dos dados (processamento local)
  • Especialização em vocabulário de segurança (Snort)
  • Baixo custo de implementação e inferência

Limitações

  • Dependência crítica de janelas de contexto amplas (>256 tokens)
  • Necessidade de dados de treinamento sintéticos de alta qualidade
  • Menor capacidade de generalização 'zero-shot' que LLMs massivos
  • Risco de alucinação em cenários muito fora do padrão de treino
